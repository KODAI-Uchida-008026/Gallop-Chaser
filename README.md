## プロジェクト概要 <a id="project-overview"></a>

| 項目 | 内容 |
|------|------|
| **ゲームタイトル** | Gallop Chaser |
| **一言で説明すると** | 馬を操作して障害物を飛び越えながら最速タイムを目指すタイムアタックゲーム |
| **ターゲット** | 昔のゲームセンターやメダルゲームのようなカジュアルに遊べるユーザー |
| **制作の目的** | 3D制作の実践　学んだことを実現できる|
| **ゲームの目的** | 加速やジャンプのタイミングを考えて最速を目指す |
| **プレイヤー操作** | A Sと← →で左右移動　Wと↑で加速　Sと↓でジャンプ(長押しで溜める) |
| **勝利条件** | ゴールラインの通過|
| **失敗条件** | なし　前に自動で進むため溜めるジャンプを意識すれば誰でもクリア可能|
| **特徴・工夫点** | 体力ゲージに影響される加速と溜めるジャンプ |

## 開発ルール <a id="development-rules"></a>

- **Git運用**
  - 1〜2時間ごとに Commit
  - 1日 2〜3回 Push
  - 作業前に必ず **Pull** して最新を取得
  - Commit メッセージは内容がわかる日本語 or 英語（例：`プレイヤー移動を追加`）

- **Unityプロジェクト設定**
  - Unity 6（URP）を使用
  - 不要アセットは増やしすぎない（軽量管理）
  - `.gitignore` は Unity 公式テンプレートを使用

- **フォルダ構成（推奨）**
```
Assets/
├─ Folder/ (SettingsやInputSystemを収納)
├─ HorsePack/ (使用アセットの追加フォルダをひとまとめに)
├─ Prefabs/
├─ Scenes/GameScene/PracticeScene/ResultScene/TitleScene/TestScene/
├─ Script/
├─ Audio/
├─ Tools/ (画像素材など)
        └─Materials/
```
TitleScene → PracticeScene → GameScene → ResultScene
