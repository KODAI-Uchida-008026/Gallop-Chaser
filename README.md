『Gallop Chaser』

■ ゲーム概要
馬を操作し、障害物を飛び越えながら
最速タイムを目指すタイムアタックゲーム。

■ 操作方法
W or ↑：前進
A / D or ← / →：左右移動
Shift：加速
S or ↓：ジャンプ (長押しで溜めてジャンプの高さを変えられる)

■ ゲーム内容
・障害物をジャンプで回避
・加速でスピードアップ
・体力管理
・タイムアタック

■ 制作目的
Unityを用いた個人制作として、
3Dゲーム制作の基礎を学ぶことを目的とする。

■ 使用アセット
・馬モデル
『Stylized Low Poly Animated Horse Pack』：https://assetstore.unity.com/packages/3d/characters/animals/mammals/stylized-low-poly-animated-horse-pack-137631
（必要に応じて後で追加）
